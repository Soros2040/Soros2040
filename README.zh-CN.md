# Julius

**量子计算 · 量子机器学习 · 研究系统**

我关注一个研究问题如何变成模型、实验与可用的系统。过去一年，我的探索从自适应投资组合策略，走向金融研究智能体，再走向量子金融研究工作台。

我目前优先关注量子计算与量子机器学习，希望争取连接数学问题、实验设计和研究软件的 RA 机会，同时继续运用量化方法与智能体系统的积累。下面的仓库提供方法、实现背景、实验报告，以及我希望继续追问的问题。

## 建议阅读路径

从量融智枢开始，了解目标函数、实验与硬件证据如何对应；通过 BenjaminAgent 了解工作流工程；通过 Alex-Fin 了解模型架构与组合评价。Julius' future 记录作品背后的选择与经历。

每个项目均提供英文与中文阅读路径。结果保留实验条件，设计、实现和执行按照贡献记录署名，参考研究与上游软件在相应仓库中致谢。

## 我的工作方式

我希望让另一位读者理解问题、方法、比较和下一步决策。因此，解释需要对应源码，结果需要保留实验身份，挑战原有假设的结果也需要得到解释。协作中，同样需要准确说明自己承担的工作。

讨论具体项目，可在相应仓库创建 Issue；了解整体方向，可阅读 [Julius' future](https://github.com/Soros2040/julius-future)。

## 完整作品与深入阅读

三份完整中文稿件和 PDF 均在 [Julius’ future 作品区](https://github.com/Soros2040/julius-future/tree/main/works)，配有双语导读、原图与公式表格索引。三个研究项目提供共七个双语案例，从方法推导和既有实例继续追踪源码、结果与局限。量融智枢已有固定候选量子核和局部可观测量研究，系统性的量子核自设计是下一阶段待讨论的方向。
